A small library, built one lab at a time

A book catalogue on Spring Boot 4: browse the shelf, add and edit books through a validated form in English or Russian, or work with the same data through a documented REST API.

RWPSF 3305 midterm project. Altai Ali, IT1-2409IS, IITU.

How the project grew

Every laboratory work added one layer to the same application. The links open the live endpoints.

  1. 1

    The first Spring Boot application

    Project from Spring Initializr, a REST controller, settings in a properties file. Variant 2: string reversal.

    /api/hello /api/info /api/reverse
  2. 2

    The IoC container

    Beans, constructor injection, @Primary and @Qualifier, life cycle, singleton and prototype. Variant 2: the reversed notifier.

    /notify /lifecycle /scopes /custom
  3. 3

    Configuration and profiles

    application.yml, dev and prod profiles, typed and validated @ConfigurationProperties, Actuator. Variant 2: app.pagination.

    /api/lab3/config /actuator/env /actuator/health
  4. 4

    Spring AOP

    Logging, timing and audit aspects, their order, the CGLIB proxy and self-invocation. Variant 1: the call counter.

    /items /proxy /stats
  5. 5

    Spring MVC

    REST and page controllers, request parameters, status codes, the model, static resources. Variant 1: title search.

    /books /books?author=Bloch /search?title=java
  6. 6

    Forms and validation

    Thymeleaf form binding, Bean Validation, messages in two languages, @ControllerAdvice. Variant 1: the ISBN check digit.

    /books/new ?lang=ru /books/999
  7. 7

    REST API

    DTOs and a mapper, 201 with Location, 204, 404 and 409 as problem details, OpenAPI with Swagger UI. Variant 1: paging.

    /api/books ?page=0&size=5 /api/books/999 Swagger UI
